## 🌟 Hakkında

Lumina, kullanıcıların dileklerini gökyüzüne uçan fenerlere dönüştürdüğü bir Flutter mobil uygulamasıdır. Eğitim amacıyla geliştirilmiştir ve Flutter'daki **tema, jest, metin girişi ve geri bildirim** konularını uygulamalı olarak gösterir.

## 🎨 Özellikler

| | Özellik | Açıklama |
|---|---|---|
| 🌌 | **Gökyüzü** | Dilekler fener olarak gösterilir, fenerler arasında gezinilir |
| 🔖 | **Kaydedilenler** | Arama yapılır, sola kaydırarak kayıt silinir |
| 🏆 | **Profil** | Seviye sistemi ve başarım rozetleri |
| 💬 | **Yorumlar** | Her dileğe yorum yazılabilir |
| 🪄 | **Yeni dilek** | Metin, kategori, emoji ve renk seçilir |
| 🎭 | **Ayarlar** | Açık/koyu tema, vurgu rengi, yazı tipi ve boyutu |

## 👆 Jestler

| Jest | Ne yapar? |
|---|---|
| 👆 Dokunma | 🌊 Işık dalgası gönderir |
| 👆👆 Çift dokunma | 💖 Dileği beğenir |
| ⏳ Uzun basma | 🏮 Fener menüsünü açar |
| ↔️ Yatay sürükleme | 🔄 Fenerler arasında geçiş yapar |
| ↕️ Dikey sürükleme | 💡 Işığı artırır veya azaltır |

## 🛠️ Kullanılan Teknolojiler

- 💙 **Flutter ve Dart**
- 🎨 **Material 3** tasarım dili
- 🔤 **google_fonts** paketi

## 🚀 Kurulum

**1️⃣ Flutter kurulumunu kontrol edin**
```bash
flutter doctor
```

**2️⃣ Proje klasörüne girin**
```bash
cd dilek_feneri
```

**3️⃣ Bağımlılıkları indirin**
```bash
flutter pub get
```

**4️⃣ Emülatör başlatın veya telefonu bağlayın**

**5️⃣ Uygulamayı çalıştırın**
```bash
flutter run
```

## 📁 Proje Yapısı

dilek_feneri/
